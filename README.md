## Reflection & Questions

### 1. When is native development more appropriate than cross-platform development?
When you need maximum hardware performance, complex 3D graphics, or deep, immediate integration with platform-specific APIs and hardware features.

### 2. How does a state change relate to the widget tree and declarative UI?
A state change triggers Flutter to rebuild the affected section of the widget tree, automatically updating the UI to reflect the new state.

### 3. Why are small commits with clear messages useful for teamwork and a portfolio?
They make code reviews easier, isolate bugs quickly, and clearly demonstrate a logical, step-by-step project history to collaborators and recruiters.
